# Typewriter

This repo contains a basic app demonstrating a `useTypewriter` hook, which
returns text character-by-character at a set speed.

Also included is the `Display` component, which renders a basic CRT-effect
box for the text to appear in.

This repo is mostly just for personal reference and to demonstrate the
styles/hook, so it's fairly barebones.

## Running the app:

```zsh
npm install
npm run dev
```
